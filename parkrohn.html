How to get names (Optional):

Note: This is completely optional - the tool works fine without athlete names. This is a workaround due to the lack of API access.

This functionality is not really suited to iPads without a keyboard attached as copy all and paste all isn't fully supported on those devices.

  1. In EMS, select all scan files for the week, and click next
  2. Press Ctrl+A (or Cmd+A on Mac) to select the entire contents of the page
  3. Press Ctrl+C (or Cmd+C on Mac) to copy
  4. Come back here and press Ctrl+V (or Cmd+V on Mac) to paste them in the box below, then click Load Names
